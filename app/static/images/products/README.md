# Images des Produits - Boutique N'Djamena

Ce dossier contient les images des produits pour votre boutique.

## Instructions

1. **Format des images** : Utilisez des images carrées (800x800px) ou rectangulaires (800x1000px)
2. **Format de fichier** : JPG, PNG ou WebP
3. **Nom des fichiers** : Utilisez des noms simples et descriptifs
   - Exemple : `t-shirt-homme-noir.jpg`, `robe-femme-rouge.png`, `chaussures-sport.jpg`

## Structure recommandée

```
products/
├── vetements/
│   ├── t-shirts/
│   ├── chemises/
│   ├── robes/
│   └── pantalons/
├── chaussures/
│   ├── baskets/
│   ├── chaussures-formelles/
│   └── sandales/
├── accessoires/
│   ├── sacs/
│   ├── montres/
│   └── bijoux/
└── autres/
```

## Comment ajouter les images

1. Placez vos images dans ce dossier
2. Dans l'admin du site, ajoutez le nom du fichier dans le champ "Image principale"
3. Le système affichera automatiquement l'image sur le site

## Taille optimale

- **Largeur** : 800px minimum
- **Qualité** : 85-90% pour JPG
- **Poids** : Moins de 500KB par image pour un chargement rapide

## Exemples de noms de fichiers

- `t-shirt-basic-blanc.jpg`
- `jeans-slim-fit-bleu.jpg`
- `robe-ete-florale.png`
- `baskets-sport-noir.jpg`
- `sac-main-cuir-marron.jpg`
- `montre-classique-argent.jpg`
